## Dimensions

- Everything else docks: the loop file is 14,929 LOC fusing streaming, the compaction judge, review mode and 30+ tool handlers (`submission_loop` itself ~1,235 lines, `streaming.rs:222-1457`; `handle_container_exec_with_params` :10160 ~1,161 lines); `tui/src/chatwidget.rs` is 44,921 LOC / 1,048 methods (`handle_code_event` :13865 = 2,262 lines) and the product surface outweighs the engine (tui 131k LOC > core 93k LOC); the documented SessionTask/ActiveTurn state design (`core/src/tasks/`, `core/src/state/`) is dead — not declared in `lib.rs` — while live state is one 20-field `State` behind a std Mutex (`codex/session.rs:121`) plus process-global singletons (`agent_tool.rs:396`, `browser/src/global.rs:8`, `codex.rs:1091`). Three loop designs in one repo, one shipped.
- Below crush (7, fusion files 2.4k/1.9k LOC); level with nanocoder (5) via a different pathology. (code-c1..c4)
