## What I read (core surface)

- **Loop**: `src/query/index.ts` (409 LOC) — clean coordinator; state in `QueryLoopState`; per-turn: abort/budget check → compaction pass (with failure circuit breaker) → memory live-refresh → budget/turn-limit prompt warnings → provider stream via per-turn `ModelRouter.select()` → streaming tool execution via `StreamingToolExecutor` → error-recovery cascade (rate-limit backoff, prompt-too-long compress-retry ≤2, network backoff, consecutive-error breaker) in `src/query/errors.ts`. Tool exec/batching/permissions in `src/query/tools.ts` (440 LOC: concurrency batching by `isConcurrencySafe`, zod validation, 100k char output cap, 120s timeout). No god files anywhere: largest non-test source is `src/harness/hooks.ts` 877.
- **Compaction**: `src/query/compress.ts` — 3-tier ladder: MicroCompact (truncate long tool/assistant content) → AutoCompact phase 1 (old tool results → stubs) → phase 2 importance-scored dropping (`scoreMessage` :19: role weights, recency, tool-call decision bonus; pinned respected) → orphan tool_result cleanup; then LLM summarization (`summarizeConversation` :139) when basic tier misses 0.7×window. Trigger: estimated tokens > 0.8×window (`query/index.ts:158`), estimate is provider `estimateTokens` or len/4 — heuristic, not pi's measured projected context. Circuit breaker: 3 consecutive compression failures disables compaction (`query/index.ts:158,186`). Plus `src/query/context-manager.ts`: per-tool output token budgets, sub-agent result folding, proactive threshold 0.6.
- **Permissions/sandbox**: `src/types/permissions.ts` — 7 modes with explicit strictness ranking (`:35`) and **narrowing-only subagent clamping** (`clampSubagentPermissionMode` :61) so a model cannot spawn a looser-permissioned subagent; tested at `src/types/permissions.test.ts:249`. Rule matching with tool specifiers + glob arg patterns (`:96-120`). `src/utils/bash-safety.ts` (450 LOC): structural command splitting, destructive/git/exfil command sets, **process-wrapper stripping** (`timeout 10 rm x` matches `rm x` rules, :52-58), feeding `checkPermission` at `permissions.ts:178,258`. Enforcement chain in `query/tools.ts:107-146`: hook `permissionRequest` first say → interactive prompt → **fail-closed deny in headless** (:217, issue #62) → every resolution logged to `~/.oh/approvals.log` (`src/harness/approvals.ts`, rotate at 2MiB, redacted previews). Workspace-trust gate for hooks/statusline scripts (`src/harness/trust.ts`, enforced `hooks.ts:555,606`). Sandbox: opt-in delegation to `@anthropic-ai/sandbox-runtime` (bwrap/sandbox-exec), wired to BashTool only (`tools/BashTool/index.ts:50`), silent passthrough on any init failure or Windows (`sandbox-runtime.ts:74-80,96-111`) — with exemplary documentation of exactly this in SECURITY.md:29-58.
